登場人物

一年戦争からグリプス戦役、第一次ネオ・ジオン抗争まで——三部作を彩る個性豊かなパイロットたちと、彼らの前に立ちはだかる強敵たち。

『機動戦士ガンダム』登場人物

ア

アムロ・レイ

Amuro Ray

15歳 / 地球連邦軍 / ガンダムパイロット

本作の主人公。機械いじりを好む内向的な少年だったが、ジオン軍の襲撃を機に偶然ガンダムに搭乗。戦場でパイロットとしての才能を開花させ、過酷な戦いを通じて精神的にも大きく成長していく。作中屈指のニュータイプとしても覚醒する。

内向的成長ニュータイプ
シ

シャア・アズナブル

Char Aznable

ジオン公国軍 / 赤い彗星

「赤い彗星」の異名を持つジオン軍のエースパイロット。ザビ家への復讐という秘めた目的を胸に、卓越した戦闘技術でアムロの宿命的なライバルとなる。冷徹に見えて情に厚い一面も持つ、シリーズを象徴するキャラクター。

エース宿命復讐
ブ

ブライト・ノア

Bright Noa

19歳 / 地球連邦軍 / ホワイトベース艦長

戦艦ホワイトベースの若き艦長。若さゆえの未熟さに悩みながらも、責任感と統率力でアムロら民間人主体のクルーをまとめ上げる。以降の続編作品でも重要な役割を担い続けるシリーズ屈指のキーパーソン。

責任感統率力成長
セ

セイラ・マス

Sayla Mass

ホワイトベース / オペレーター

実はシャア・アズナブルの妹・アルテイシア・ソム・ダイクンという出自を隠しホワイトベースに搭乗する女性。冷静な判断力を持ち、オペレーターとして、また時にモビルスーツパイロットとしても戦場を支える。

秘密の出自冷静家族の絆
カ

カイ・シデン

Kai Shiden

ホワイトベース / モビルスーツパイロット

皮肉屋で口が悪いが、根は仲間思いの民間人出身パイロット。戦闘経験を積む中で徐々に頼れる戦力へと成長していく。

皮肉屋成長
ラ

ララァ・スン

Lalah Sune

ジオン公国軍 / ニュータイプ

シャアに見出された天性のニュータイプ。アムロとも心を通わせる中で、二人の宿命的な対比が描かれる。物語終盤における最大の悲劇の一つを象徴する存在。

ニュータイプ悲劇純粋

『機動戦士Ζガンダム』登場人物

カ

カミーユ・ビダン

Kamille Bidan

エゥーゴ / Ζガンダムパイロット

本作の主人公。ティターンズ士官への反発から事件を起こし、成り行きでΖガンダムのパイロットとなる。感受性が強く激しやすい性格で、戦争の理不尽さと人間の悪意に何度も直面しながら、強いニュータイプとして覚醒していく。

激情ニュータイプ葛藤
ク

クワトロ・バジーナ（シャア・アズナブル）

Quattro Bajeena / Char Aznable

エゥーゴ / 前作の登場人物

正体を隠しエゥーゴの指揮官として再登場するシャア・アズナブル。カミーユの才能を見出し、師のような存在として導く一方、自身もまた過去との決着に向き合っていく。

変装師弟宿命
ブ

ブライト・ノア

Bright Noa

エゥーゴ / アーガマ艦長

前作から引き続き登場する艦長。今作では新戦艦アーガマを率い、若く未熟なカミーユたちを時に厳しく、時に温かく導いていく。

指揮官継承
ジ

ジェリド・メサ

Jerid Messa

ティターンズ / モビルスーツパイロット

ティターンズの若手士官。カミーユとの因縁から幾度も激突するライバル的存在。功名心と劣等感の間で揺れ動く、人間味あふれるキャラクター。

ライバル功名心
パ

パプテマス・シロッコ

Paptimus Scirocco

ティターンズ→独自勢力 / 強力なニュータイプ

圧倒的なカリスマと戦闘能力を持つ野心家。ティターンズを利用しながら独自の野望を追求する、シリーズ屈指の強敵として立ちはだかる。

野心カリスマ強敵
ハ

ハマーン・カーン

Haman Karn

アクシズ（ジオン残党） / 指導者

ジオン残党勢力アクシズを率いる若き女性指導者。優れたニュータイプ能力とカリスマ性を併せ持ち、三つ巴の抗争に大きな影響を及ぼす。続く『ΖΖガンダム』にも引き続き登場する。

カリスマ指導者ニュータイプ

『機動戦士ガンダムΖΖ』登場人物

ジ

ジュドー・アーシタ

Judau Ashta

14歳 / シャングリラのジャンク屋 / ΖΖガンダムパイロット

スペースコロニー「シャングリラ」でジャンク屋として妹たちを養っていた明朗な少年。ひょんなことからΖΖガンダムのパイロットとなり、大人たちの戦争に巻き込まれながらも持ち前の明るさとニュータイプとしての力で困難を乗り越えていく。

明朗妹思いニュータイプ
ブ

ブライト・ノア

Bright Noa

エゥーゴ→地球連邦軍 / アーガマ艦長

前2作から続投する艦長。今作では若く粗削りなジュドーたちのクルーをまとめ上げ、宇宙世紀三部作を通じた「継承」の象徴的存在となる。

継承指揮官
リ

リィナ・アーシタ

Leena Ashta

ジュドーの妹

ジュドーが命を懸けて守ろうとする幼い妹。物語序盤で誘拐され、彼女の救出がジュドーが戦いに身を投じるきっかけとなる。

家族愛きっかけ
ハ

ハマーン・カーン

Haman Karn

ネオ・ジオン / 指導者

前作から続投する、ネオ・ジオンを率いる指導者。地球圏制覇を目指してジュドーたちの前に立ちはだかる。同じニュータイプであるジュドーに複雑な感情を抱く場面も描かれる。

カリスマ宿敵
プ

プル

Puru

ネオ・ジオン / 強化人間

ネオ・ジオンによって生み出された強化人間の少女。ジュドーとの関わりの中で心を通わせていくが、その出自が大きな悲劇を生む。

強化人間悲劇純粋
マ

マシュマー・セロ

Mashymre Cello

ネオ・ジオン / 熱血漢の士官

ハマーンへの熱烈な忠誠を胸に戦うネオ・ジオンの士官。豪快で情熱的な性格から、シリーズきっての人気キャラクターの一人となった。
