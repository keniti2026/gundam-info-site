# 機動戦士ガンダム UC三部作 総合情報サイト

『機動戦士ガンダム』(1979)・『機動戦士Ζガンダム』(1985)・『機動戦士ガンダムΖΖ』(1986) の宇宙世紀（Universal Century）オリジナル三部作をまとめたファンサイトです。ビルド工程を持たない静的HTML/CSS/JSサイトとして構築しています。

シャア・アズナブルの逆襲以降の続編作品や、ガンダムSEED・00等の別世界観（アナザーガンダム）作品は対象外とし、宇宙世紀オリジナル三部作のみを扱っています。

## 公開URL

https://keniti2026.github.io/gundam-info-site/

（GitHub Pages で `main` ブランチ直下 `/` を公開設定にしています）

## ローカルでの確認方法

Python が入っていれば、リポジトリのルートで以下を実行してください。

```
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開くと確認できます。

## ページ構成

| ファイル | ページ内容 |
|---|---|
| `index.html` | トップページ |
| `works.html` | 作品一覧（三部作・年表） |
| `characters.html` | 登場人物（作品別タブ切替） |
| `mechanics.html` | メカニック（モビルスーツ・ミノフスキー粒子・ニュータイプ） |
| `themes.html` | テーマ・ジャンル解説 |
| `history.html` | 歴史・文化的影響（年表） |
| `links.html` | 外部リンク集 |
| `gundam.html` | 『機動戦士ガンダム』特設ページ |
| `zgundam.html` | 『機動戦士Ζガンダム』特設ページ |
| `zzgundam.html` | 『機動戦士ガンダムΖΖ』特設ページ |

共通ファイル:

- `style.css` — 全ページ共通のスタイル（ダークテーマ・ホワイト/レッド/ブルー/イエローの宇宙世紀配色・レスポンシブ対応）
- `script.js` — ナビゲーションのアクティブ表示・モバイルメニュー・ページ内タブ切替
